# Ported files

Every file ported from the vendor at v1.17.10 is listed here. A listed file
keeps the vendor's header lines intact, followed directly by a
`// Modified by hoardDB, <date>: <summary>` line (`internal/repocheck`
enforces both). Put the library path in backticks in the first column.

The last column names the header form of the vendor source file itself: `mgo`
(copyright, licence, then the "Based on gopkg.in/mgo.v2/bson" and "See
THIRD-PARTY-NOTICES" lines) or `apache` (the five copyright and licence lines
only). `internal/repocheck` requires exactly that form for that file, and the
oracle compares the column with the vendor source in the module cache.
